# Ochmistrz

*Budżet domowy dla całej załogi.*

Ochmistrz to program dla Windows do prowadzenia budżetu domowego: zapisujesz wydatki, przychody i przekazania na oszczędności, widzisz, ile zostało do dyspozycji (nadwyżka przechodzi na kolejny miesiąc), ustalasz miesięczne limity kategorii i pilnujesz stałych opłat. Kilka osób może prowadzić **jeden wspólny budżet** – każda na swoim komputerze, ze zmianami wymienianymi przez wspólny folder (udostępniony katalog, dysk sieciowy albo zewnętrzny).

Ochmistrz jest z tej samej rodziny co [Sternik](https://github.com/Kargadann/sternik-wydania) – programu do planu inwestycyjnego i oszczędności.

## Pobierz
Najnowsza wersja: **[Wydania → Latest](../../releases/latest)** – plik `Ochmistrz-…-instalator.exe`.

Przy pierwszym uruchomieniu instalatora Windows może pokazać okno „System Windows ochronił ten komputer” (program nie ma płatnego podpisu cyfrowego) – kliknij **„Więcej informacji” → „Uruchom mimo to”**. Instalacja nie wymaga uprawnień administratora.

## Instrukcja
[INSTRUKCJA.md](INSTRUKCJA.md) – instalacja, wpisy i podsumowanie miesiąca, plan, stałe opłaty, wspólny budżet, kopie zapasowe i aktualizacje.

## Prywatność
Twoje dane zostają **na Twoim komputerze** (`%APPDATA%\Ochmistrz`) i – jeśli go ustawisz – we wspólnym folderze, który wskażesz. Program nie wysyła ich nigdzie. Raz dziennie pyta tę stronę o numer najnowszej wersji – bez żadnych danych.

## Wymagania
Windows 10 lub 11 (64-bit).

To repozytorium zawiera tylko wydania i instrukcję.
